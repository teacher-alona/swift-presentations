Рівень 1Лічильник
Кнопки «+1», «−1» і «Скинути», число по центру. Число стає червоним, якщо менше нуля.
Натисніть, щоб побачити підказку

      
Потрібні: @State private var count = 0, три Button, Text("\(count)"). Для кольору: .foregroundStyle(count < 0 ? .red : .primary).

    
Рівень 2Лайк
Серце перемикається між контуром і заливкою. Поруч підпис «Подобається» або «Не подобається».

      
Потрібні: @State private var liked = false, liked.toggle(), Image(systemName: liked ? "heart.fill" : "heart").

Якщо не виходить
Типові помилки. Клацніть, щоб дізнатися причину

  

    
ПОМИЛКА 1
var count = 0
Button("+1") { count += 1 }
ПРИЧИНА
Немає @State. Xcode: Cannot assign to property: 'self' is immutable. Додайте @State private.

    
ПОМИЛКА 2
Text(count)
ПРИЧИНА
Text приймає рядок, а count це число. Xcode: requires that 'Int' conform to 'StringProtocol'. Напишіть Text("\(count)").

    
ПОМИЛКА 3
Button("Лайк") {
    liked.toggle
}
ПРИЧИНА
Без дужок toggle не викликається, тож нічого не станеться. Пишіть liked.toggle().

    
ПОМИЛКА 4
pips = Int.random(in: 1..6)
ПРИЧИНА
Діапазон у Swift пишуть із трьома крапками: 1...6. Так число 6 теж входить у діапазон.
