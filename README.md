# Swift: презентації до уроків

Інтерактивні презентації для курсу Swift (10 клас). Кожен урок лежить в окремій папці й відкривається як звичайна веб-сторінка, без встановлення.

| Заняття | Тема | Відкрити |
|------|------|----------|
| Пара | Кнопки та @State | [lesson-05-buttons-state](lesson-05-buttons-state/index.html) |

## Керування презентацією

- `←` `→` або свайп: слайди
- `F`: повний екран, `O`: огляд усіх слайдів
- `N`: нотатки вчителя, `T`: режим вчителя (показує слайд з еталонним кодом)

## Додати новий урок

Створіть папку `lesson-NN-тема/` з файлом `index.html` і додайте рядок у `index.html` у корені та в таблицю вище.
